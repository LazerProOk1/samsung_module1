# DungeonQuest

Консольная RPG-игра на Java: герой пробирается через поле 5×5 к замку, побеждая монстров с помощью логических заданий.

## Полное описание

DungeonQuest — текстовая квест-игра, написанная на Java с использованием принципов ООП. Игрок управляет героем на поле 5×5, цель — добраться до замка в верхней строке поля.

На пути встречаются три вида монстров:
- **Мм** (маленький монстр) — задаёт простой пример на сложение
- **Мб** (большой монстр) — задаёт пример на умножение и вычитание; сложность зависит от выбранного уровня игры
- **Мк** (колдун) — предлагает расшифровать слово, зашифрованное шифром Цезаря; уровень сложности влияет на длину слова, наличие подсказок и количество попыток

Герой перемещается по координатам на одну клетку по горизонтали или вертикали. При входе на клетку с монстром начинается испытание. Неверный ответ снимает одну жизнь из трёх. При потере всех жизней — поражение, при достижении замка — победа.

В начале игры выбирается уровень сложности от 1 до 5, который влияет на задания большого монстра и колдуна.

## Запуск

```
javac src/*.java -d out
java -cp out Main
```

## Структура проекта

```
src/
├── Main.java          — игровой цикл и поле
├── Person.java        — главный герой
├── Monster.java       — маленький монстр
├── BigMonster.java    — большой монстр
└── MysticMonster.java — монстр-колдун (шифр Цезаря)
```
